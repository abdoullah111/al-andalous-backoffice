# Mizan Backoffice

Application web de gestion d’articles (bijoux, lingots et pièces).
Elle permet d’afficher, rechercher, trier, créer, modifier et supprimer des articles via une API REST locale.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript Vanilla (ES Modules)
- JSON Server
- Fetch API
